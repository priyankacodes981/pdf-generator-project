# PDF Generator using Python

A professional Python project that generates a structured multi-page PDF document from CSV data using **FPDF** and **Pandas**.

---

## Project Overview

This project reads topics and page counts from a CSV file and automatically creates a formatted PDF document.

The generated PDF includes:

- Topic headings
- Multiple pages
- Custom text colors
- Horizontal lines
- Footer text
- Automatic PDF generation

---

## Technologies Used

- Python
- Pandas
- FPDF

## How to Run

Install required libraries:

```bash
pip install pandas fpdf
```

Run the project:

```bash
python main.py
```
